# Contributing to PerformanceListView

First off, thank you for considering contributing! It's people like you that make `performance_list_view` better for everyone.

### 📝 How Can I Contribute?

* **Reporting Bugs:** Open an issue with a clear description and steps to reproduce.
* **Suggesting Enhancements:** Open an issue explaining why the feature would be useful.
* **Pull Requests:** * Ensure your code follows the Flutter style guide.
    * Add comments to complex logic.
    * Update the `example` app if you add a new feature.

### 🛠 Development Setup

1. Fork the repo and clone it locally.
2. Run `flutter pub get` in the root directory.
3. Use the `example` folder to test your changes.
4. Run `flutter analyze` before committing.

**Thank you for your help!**
